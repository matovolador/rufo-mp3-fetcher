# RUFO MP3 FETCHER

## About

This software is a python wrapper for ffmpeg and youtube_dl.

## Requirements

You will need [ffmpeg](https://ffmpeg.org/) in your system PATH.
Python 3.6.x
Virtualenv

## Execution

```bash
source venv/bin/activate
python main.py "your-desired-url" --normalize --verbose
```
